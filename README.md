# Epoint Worklog Manager

## 简介

本插件是一款专为Epoint公司员工设计的浏览器扩展，旨在简化非功能日志申请流程，提高工作效率。通过本插件，您可以预设项目信息、快速添加和管理工作日志，并将日志自动填充到公司的非功能任务申请系统中，快速进行非功能任务申请。

## 主要功能

- **日志管理**：
  - 支持添加、修改和删除工作日志。
  - 日志内容包括项目、日志内容、工时和日期。
  - 待填写的日志会以列表形式展示，方便管理。

- **自动填充**：
  - 点击“提交”按钮，可将待填写的日志自动填充到Epoint公司的日志页面。
  - 自动判断日志页面是否打开，并给出相应提示。
  - 自动处理日志页面表格的行数，确保数据正确填充。

- **项目预设**：
  - 支持预设项目信息，包括项目名称、蓝图目标、工作场景和任务审核人。
  - 新增日志时，可直接从预设列表中选择项目，无需手动输入。

- **状态指示器**：
  - 在页面底部提供一个状态指示器，实时显示当前是否处于日志填写页面。
  - 统计并显示待填写日志的总工时，方便您跟踪工作进度。

- **美观易用的界面**：
  - 采用现代化、扁平化的设计风格，界面清新大方。
  - 提供“待填写”和“已填写”两个标签页，方便您管理不同状态的日志。

## 如何使用

1. **安装插件**：
   - 打开Chrome浏览器，进入“扩展程序”页面。
   - 开启“开发者模式”。
   - 点击“加载已解压的扩展程序”，选择本插件的根目录。

2. **预设项目**：
   - 点击插件图标，打开插件页面。
   - 进入“预设”页面，添加您常用的项目信息。

3. **添加日志**：
   - 在“待填写”页面，点击“添加”按钮。
   - 填写项目、日志内容、工时和日期等信息。
   - 添加的日志会显示在下方的列表中。

4. **提交日志**：
   - 打开Epoint公司的非功能任务申请页面（可以在插件待填写页面点击“申请非功”按钮快速跳转）。
   - 回到插件待填写页面，点击任务列表中的“提交”按钮。
   - 插件会自动将您在“待填写”页面添加的日志填充到日志系统中。

## 注意事项

- 请确保在提交日志前，已经打开了Epoint公司的日志填写页面。
- 如果日志页面默认加载的数据行数不够，插件会自动创建新行进行填充。
- 预设信息修改后，会自动同步更新任务列表和项目分类标签。

## 数据持久化

本插件使用浏览器的localStorage机制实现数据持久化存储，确保您的数据在关闭浏览器后仍然保留：

- **日志数据**：所有待填写和已填写的日志都会自动保存到localStorage中，无需手动操作
- **预设项目**：您添加的预设项目信息会实时保存，添加、修改或删除预设项目后会立即持久化
- **配置信息**：包括需求标签、工作类型、蓝图预设、工作场景预设、任务审核人预设等配置都会自动保存
- **自动同步**：当您修改预设信息时，插件会自动同步更新任务列表和项目分类标签

所有数据都存储在您的本地浏览器中，不会上传到任何服务器，确保数据安全和隐私。
